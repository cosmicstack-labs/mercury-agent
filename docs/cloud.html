Everything Cloud

What you get when you connect.

⚡

Plug-and-play setup

  • One command pairs your agent: mercury cloud connect
  • Browser-based pairing URL — no API keys to copy
  • No port forwarding, reverse proxy, or DNS needed
  • Works behind NAT and firewalls out of the box
🔒

Self-healing auth

  • JWT auto-rotated before expiry via single-use refresh token
  • Long-lived agent API key for headless self-recovery
  • Never needs browser re-pairing — stays online indefinitely
  • Shared token store keeps WS client and provider in sync
🧠

Collaborative knowledge

  • Shared memory pool across all your agents
  • Search cross-agent context after local Second Brain retrieval
  • 5-minute SQLite cache per query to cut network cost
  • Fall-open design — cloud misses never block the chat turn
🎛️

Remote dashboard

  • Manage agents from cloud.mercuryagent.sh
  • Send messages, install skills, view memory remotely
  • Monitor agent status and WebSocket health
  • Conversation sync across devices
📡

Cloud WebSocket

  • Persistent WSS connection with 30-second heartbeats
  • Exponential backoff reconnect (up to 50 attempts)
  • Pre-connect token rotation — never handshakes with expired JWT
  • Stays alive in background daemon after you exit the terminal
🚀

Fast & accurate

  • Mercury Flash for instant responses
  • Mercury Pro for complex reasoning tasks
  • Model selection at pairing time — switch later anytime
  • OpenAI-compatible API — proven and reliable

Agent Controls

Full control from the CLI and the cloud dashboard.

1

Connect

mercury cloud connect

Pair with Mercury Cloud via browser. Choose your model.

2

Manage remotely

Open cloud.mercuryagent.sh to send messages, install skills, view memory, and monitor status.

3

Disconnect anytime

mercury cloud disconnect

Clears all Cloud credentials and switches back to your offline provider.
